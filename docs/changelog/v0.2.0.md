# v0.2.0-next

::: callout warning Prerelease
This release is still in development and has not been tagged yet.
:::

A Zirric program still runs one thing at a time. What it can now do is wait on more than one of them: a key and a timer, a slow job and a user who presses `q`, several files handled as they become ready.

## Implemented Proposals

- [ZE-025 Routines and Channels](/proposals/ZE-025-routines-and-channels) — the [`co`](/stdlib/co) module: routines, the scopes that own them, and channels between them. No new syntax, no new keyword, no new operator.

## Notable Changes

- `zirric cave new` follows the created `Cavefile` with the commands and documentation links a new project needs next.
- `zirric ci forgejo` and `zirric ci github` write a workflow that checks formatting and runs the tests, installing the toolchain with [`setup-action`](https://code.knabel.dev/zirric-lang/setup-action).
- `zirric --help` sections its commands and the project's own tasks.

## Bug Fixes

- A closure written inside a `for` expression body can reach a variable of the enclosing function. The loop body has a symbol table of its own while running in the same frame, so such a reference was resolved against the frame's own captures — reporting an internal error, or silently reading an unrelated captured value when the indices happened to line up.
