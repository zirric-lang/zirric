# v0.0.1

Initial release of the Zirric programming language. Most basic expressions, functions, `let`-variables, and statements were implemented along with a bytecode compiler and virtual machine.

- [A New Beginning](https://www.vknabel.com/posts/2025-09-16-a-new-beginning/) — Describes the basic idea behind Zirric and compares it to [Lithia](https://code.knabel.dev/lithia-lang/lithia).
- [Going Virtual](https://www.vknabel.com/posts/2025-09-28-going-virtual/) — The switch to a bytecode compiler and interpreter with massive performance improvements over Lithia's tree-walking interpreter.

## Tooling

- [Tree-Sitter-Zirric v0.1.0](https://code.knabel.dev/zirric-lang/tree-sitter-zirric/releases/tag/v0.1.0) — Initial Tree-Sitter grammar for syntax highlighting, covering the [ZE-001 Base Language](/proposals/ZE-001-base-language) syntax.
