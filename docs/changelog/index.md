# Changelog

::: changelog

== v0.2.0-next

Routines, scopes and channels in the new `co` module, and `os.timer` to go with them. [Full release notes →](/changelog/v0.2.0)

== v0.1.0

Explicit mutability, unified `fn` syntax, type hints with `is`/`switch` matching, qualified module names, new declaration keywords, iterable and more. [Full release notes →](/changelog/v0.1.0)

== v0.0.1

Initial release with basic expressions, functions, `let`-variables, a bytecode compiler, and virtual machine. [Full release notes →](/changelog/v0.0.1)

:::
